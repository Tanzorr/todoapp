📖 How a typical request flows

1
User clicks a button in the browser (e.g. "Add task").
The browser JS (src/api-client.js) makes a fetch('POST /api/tasks', { title: '...' }) call.
2
The Express server receives the request. tasks.routes.js decides which controller to call → tasks.controller.js reads the request body → tasks.service.js validates the data → tasks.repository.js builds the SQL query.
3
SQL runs in MySQL. For example: INSERT INTO tasks (title) VALUES (?). The database saves the row and returns the generated id.
4
Response travels back: MySQL → Repository → Service → Controller → res.status(201).json({ id, title, done, createdAt }) → The browser receives JSON → src/render.js renders the new task in the DOM.
